配置导出与部署
学员扫码后会自动从网站加载最新的架构和名单配置。
每次修改批次、架构或名单后，请点击下方按钮导出配置文件，然后把下载的 config.json 上传到 GitHub 仓库根目录并推送。
部署步骤
1. 在「批次管理」中配置好入职日期、架构、名单
2. 点击上方「导出配置文件」按钮，下载 config.json
3. 把 config.json 放到 GitHub 仓库 sign-in 目录下
4. 执行 git add config.json && git commit -m "update config" && git push
5. 等待 1-2 分钟，学员扫码即可看到最新配置
签到记录说明
本方案不使用云数据库，签到记录保存在学员各自的手机浏览器中。
学员签到成功后会显示签到凭证（姓名、架构、时间），可截图发到群里核对。
管理员可在「签到统计」中导出签到名单模板，现场人工核对。
