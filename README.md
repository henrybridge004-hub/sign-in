# 培训签到系统

一个网页完成：大屏签到二维码 → 学员扫码输姓名 → 自动匹配所属架构 → 显示该架构的「加入邀请」和「入职登记」两个钉钉二维码 → 管理员后台每周更新学员名单。

**部署文件：`index.html` + `config.json`**

## 工作原理

- **架构与二维码链接**：9个架构（探迹、探迹智能、探域、汉数、数字贸易港、探呼、探讯、探力、探力（济南））已固定写死在 `index.html` 里，每个架构含两个钉钉链接（加入邀请、入职登记）。学员签到后页面实时生成高清二维码（220px，二维码服务在线生成）。
- **名单**：管理员在后台拖入 Excel/CSV（自动提取「姓名」「所属钉钉」两列），自动模糊匹配架构；保存后同步到 GitHub 的 `config.json`。
- **学员端**：扫码打开页面 → 自动加载最新名单 → 输入姓名 → 匹配架构 → 动态生成该架构的两个二维码。
- **签到记录**：保存在签到设备浏览器本地；若配置了钉钉群机器人 Webhook，每次签到还会**实时发送签到流水到钉钉群**，管理员在群里即可核对谁已签到（推荐）。

## 一、部署（GitHub Pages，免费）

1. 把整个目录（`index.html`、`config.json`、`qrcodes/`）推送到 GitHub 仓库 `sign-in`（master 分支）。
2. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 `master`，目录 `/ (root)` → **Save**。
3. 等 1–2 分钟，访问 `https://你的用户名.github.io/sign-in/`。
4. 把这个网址生成二维码（草料二维码等）投屏。

## 二、日常使用（管理员）

1. 打开网址 → 右下角「管理员入口」→ 输入密码 `0288`。
2. **名单管理**：拖入每周的 Excel 名单（含「姓名」「所属钉钉」两列），自动匹配架构，匹配不上的标红提示。可添加/删除/清空/导出名单。
3. **签到情况**：查看名单中谁已签到/未签到，可导出 CSV。
4. **同步设置**：首次使用配置 GitHub Token（Fine-grained token，选 sign-in 仓库，Contents 权限 Read and write），之后每次更新名单会自动同步到 GitHub，学员端扫码即见最新名单。
5. **（可选）钉钉群实时上报**：同步设置页底部填入钉钉群机器人 Webhook（自定义关键词设为「签到」），学员签到后流水实时发到钉钉群。

## 三、学员签到流程

1. 学员用钉钉扫描大屏上的签到二维码。
2. 手机页面输入姓名，点击「签到」。
3. 系统自动匹配所属架构，实时生成两个高清二维码（用钉钉扫码即可）：
   - 第 1 个：加入该架构的钉钉邀请码（用钉钉扫码加入）
   - 第 2 个：该架构的入职登记码（用钉钉扫码填写）
4. 页面显示签到凭证：姓名、架构、签到时间。

## 四、重要说明

- 管理员密码固定为 `0288`（写在 `index.html` 顶部 `DEFAULTS.adminPassword`）。
- 名单同步依赖 GitHub API；同一账号在多个设备上配置一次 Token 后，修改即自动同步。
- 签到记录存在签到设备本地浏览器，管理员后台看到的是管理员本机的签到情况（多管理员各自独立，属正常现象）。
- GitHub Pages 国内访问可能较慢，属平台限制。
